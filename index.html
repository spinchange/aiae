AIAE: original vs. detrended

The original reading compares today with all of history since 1952. The detrended reading compares it with the last 20 years only. When the two disagree, the gap shows how much a "stocks are expensive" verdict depends on assuming the old average still applies.

About this page

  • Updates itself. A GitHub Action checks FRED every Tuesday and republishes when the Fed's quarterly Z.1 release adds a new quarter (mid-March, June, September and December).
  • Live FRED chart of the original AIAE: fred.stlouisfed.org/graph/?g=2178M
  • Code and raw data: github.com/spinchange/aiae (data/aiae.json)

AIAE = (NCBEILQ027S + FBCELLQ027S) ÷ (those + BCNSDODNS + CMDEBT + FGSDODNS + SLGSDODNS + DODFFSWCMI). Detrended = AIAE minus its trailing 80-quarter average (pre-1952 data is annual and is included in early averages). Source: Federal Reserve Z.1 Financial Accounts via FRED.
